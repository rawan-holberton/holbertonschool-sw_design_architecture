# UML Introduction — Library Loan System

## Introduction

This project introduces **Unified Modeling Language (UML)** as a way to represent software systems.

The goal is to analyze a textual system description and translate it into:

- a **UML class diagram**
- a **UML sequence diagram**

All diagrams are written using **Mermaid syntax**.

---

## Project Objective

You are working on a **Library Loan System**.

The system manages:

- books
- users
- loans

Your task is to model the system structure and behavior strictly based on the given description.

---

## Learning Objectives

By the end of this project, you should be able to:

- extract classes, attributes, and methods from a text description
- identify relationships between classes
- determine multiplicities
- model systems using UML class diagrams
- model interactions using UML sequence diagrams
- write diagrams using Mermaid syntax

## General Requirements

- Environment: **Ubuntu 20.04**
- Diagrams must be written in **Mermaid format**
- File names must match exactly the specification
- Use **Python-style types** (`str`, `bool`, etc.)
- Do not add elements not present in the problem description
- Do not rename classes, attributes, or methods
- Diagrams must be syntactically valid Mermaid code
- The project is automatically graded

---

## Project Rules

You must:

- carefully extract all required elements from the description
- respect exact naming conventions
- model correct relationships and multiplicities
- ensure diagrams reflect only the given system behavior
